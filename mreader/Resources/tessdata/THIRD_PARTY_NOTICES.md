# Japanese vertical OCR model

`jpn_vert.traineddata` is the vertical Japanese LSTM model from the
[Tesseract tessdata_fast repository](https://github.com/tesseract-ocr/tessdata_fast).
The repository documents that this model is trained on vertically rendered
Japanese text and licenses its data under the Apache License 2.0.

- Source: https://github.com/tesseract-ocr/tessdata_fast/blob/main/jpn_vert.traineddata
- License: Apache-2.0
- License text: https://www.apache.org/licenses/LICENSE-2.0
- Retrieved for MReader release build: 2026-08-24
